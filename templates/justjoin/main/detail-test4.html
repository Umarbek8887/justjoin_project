Job Description

Dołącz do zespołu Synthi AI!

Tworzymy Synthi AI – aplikację, która zmienia naukę języków w coś naprawdę angażującego. Dzięki AI nauka staje się interaktywna, dostosowana do użytkownika i po prostu działa w praktyce. Mamy już 70 000 aktywnych użytkowników, a liczba ta rośnie w zawrotnym tempie.

Chcesz sprawdzić, jak to działa? Zajrzyj tutaj:
en.synthiaiapp.com

Co będziesz robić?

  • Rozwijać i utrzymywać backend aplikacji oparty na Node.js i NestJS
  • Budować i optymalizować interfejsy użytkownika w React i React Native
  • Integrować rozwiązania AI i uczenia maszynowego w produkt
  • Projektować i wdrażać API RESTful oraz mikroserwisy
  • Pracować z bazami danych MongoDB i PostgreSQL
  • Uczestniczyć w code review i doskonalić kulturę inżynierską zespołu

Czego szukamy?

  • Znajomości JavaScript / TypeScript na poziomie Junior
  • Doświadczenia z React (frontend) i Express.js lub NestJS (backend)
  • Podstawowej znajomości Figma i umiejętności pracy z designem
  • Chęci do nauki i rozwijania się w dynamicznym środowisku startup
  • Mile widziane: znajomość Microservices, MongoDB, React Native
